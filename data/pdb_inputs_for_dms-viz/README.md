# PDB (Protein Data Bank) inputs for `dms-viz`

## site maps
Site maps mapping reference site used in DMS to protein sites in PDB, used in [configure-dms-viz](https://dms-viz.github.io/dms-viz-docs/preparing-data/data-requirements/#sitemap).

## PDB files
In cases where it is not possible to just use the biological assembly or asymmetric unit from the PDB, files are downloaded and manually edited:

 - [5c6b_trimer.pdb](5c6b_trimer.pdb): the `5c6b` biological assembly is two head-to-head trimers, so here we have edited the biological assembly to just be one trimer.
