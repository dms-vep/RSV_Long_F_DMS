# Non-pipeline analyses

This subdirectory has analyses run manually outside the main pipeline:

 - [./tree_fig](tree_fig): nice rendering of phylogenetic trees for paper
 - [./validations](validations): neutralization assay results for point mutant and strain validations and correlation plots
 - [./logo_plots](logo_plots): logo plots displaying top escape sites for key antibodies 
 - [./antigenic_regions](antigenic_regions): plots of cell entry effects at sites within defined antigenic regions
 - [./colored_top_escape_sites](colored_top_escape_sites): faceted escape summary plots that highlight each Fab antibody's top escape sites in distinct colors across the antibody and sera panels (all 5 human sera), including a standalone plot of the hSera average (across all 5 sera) and a sera plot using a fully distinct per-antibody color scheme
 - [./sera_validations](sera_validations): neutralization assay results for point mutants for sera validations
 - [./multi-mut_nirsevimab](multi-mut_nirsevimab): neutralization curves of Nirsevimab IgG and Fab against WT and single/combination escape mutants
 - [./IgG_Fab_neuts](IgG_Fab_neuts): neutralization curves comparing IgG vs Fab forms of each antibody (Nirsevimab, RSM01, 1B6, Clesrovimab, 1A2) against RSV A Long and RSV B B1
