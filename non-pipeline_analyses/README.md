# Non-pipeline analyses

This subdirectory has analyses run manually outside the main pipeline:

 - [./tree_fig](tree_fig): nice rendering of phylogenetic trees for paper
 - [./validations](validations): neutralization assay results for point mutant and strain validations and correlation plots
 - [./logo_plots](logo_plots): logo plots displaying top escape sites for key antibodies 
 - [./antigenic_regions](antigenic_regions): plots of cell entry effects at sites within defined antigenic regions
 - [./colored_top_escape_sites](colored_top_escape_sites): faceted escape summary plots that highlight each Fab antibody's top escape sites in distinct colors across the antibody and sera panels
